# Modelling Fractions: Part 3

Extends the `Fraction` class from Part 2 with comparison methods.

The program reads two fractions and prints the result of comparing them.

## Output format

```
[a] > [b]   — if a is greater than b
[a] < [b]   — if a is less than b
[a] = [b]   — if a equals b
```

## Notes

- Fractions are reduced to lowest terms before display
- Add `isGreaterThan`, `isLessThan`, `isEqual` methods to `Fraction`
- Hint: cross-multiply to compare without floating point
