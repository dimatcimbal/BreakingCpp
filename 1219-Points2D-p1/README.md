# Points in 2D: Part 1

A `Point2D` class representing a point in two-dimensional space.

The program reads two points and prints the distance between them using the Pythagorean theorem.

## Input format

Each point is given as `x y` or `x, y` on a single line.

## Notes

- `distanceTo(Point2D that)` — returns the Euclidean distance between two points
- Formula: `sqrt((x2-x1)^2 + (y2-y1)^2)`
- Coordinates are `double`
