# Class Basics

A **class** is a blueprint that bundles related data and behaviour into a single type. Each variable you create from that blueprint is called an **object** (or instance).

The starter code defines a `Person` class with two public data members and a free `print` function.

## Tasks

1. Run the code and observe the output.
2. Add at least one more data member to `Person` (e.g. `email` or `occupation`).
3. Update `main` to set and print the new member.
4. Experiment: what happens if you try to access a member that doesn't exist?
